# One-Line Cat Joke

A tiny TypeScript program that writes a single one-line joke about cats to `/output/entry.txt`.

Run it with:

```sh
node main.ts
```

The joke:

> My cat ignored me all day, then at 3 a.m. sat on my chest and purred in my face like a tiny manager delivering my performance review.

Built for the make.fun bounty "The One-Line Cat Joke That Lands".
